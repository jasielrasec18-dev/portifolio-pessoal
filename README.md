# Portfólio Pessoal - Jasiel Rasec

## 📋 Descrição

Este é o meu portfólio pessoal, um site responsivo desenvolvido para apresentar minhas habilidades, experiências e projetos como desenvolvedor Full Stack. O site foi construído utilizando tecnologias modernas da web para oferecer uma experiência visual atraente e intuitiva.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica do site
- **CSS3**: Estilização responsiva e moderna

## 🛠️ Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/jasielrasec18-dev/portifolio-pessoal.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd portifolio-pessoal
   ```

3. Abra o arquivo `index.html` no seu navegador preferido.

Como este é um site estático, não há necessidade de instalar dependências ou executar um servidor local. Basta abrir o arquivo HTML diretamente no navegador.

## 📱 Funcionalidades

- **Design Responsivo**: Otimizado para desktop, tablet e mobile
- **Seções Organizadas**:
  - Hero: Apresentação inicial
  - Sobre Mim: Informações pessoais e tecnologias
